# Close Guess Daily

Build a complete mobile-first web game called "CLOSE".

The concept is: "Guess it. See how close you are to everyone else."

Create a clean, addictive, premium-looking global daily guessing game.

GAME:

- Every day the player gets 5 visual estimation questions.

- Show one image per question.

- Ask questions such as:

  "What percentage of this image is red?"

  "How many objects are in this image?"

  "How tall is this building?"

  "How many people are in this crowd?"

- The player enters a numerical guess.

- After submitting, reveal the correct answer.

- Calculate how close the player's guess was.

- Show the player's score.

- After all 5 questions, show a final score and ranking screen.

IMPORTANT:

- This is NOT a gambling or betting website.

- Players never deposit money.

- Do not promise cash prizes.

- The game is free to play.

DESIGN:

- Extremely modern and minimal.

- Dark background.

- Large image cards.

- Smooth animations.

- Mobile-first and optimized for iPhone.

- English language because the target audience is worldwide.

- Make it feel like a polished viral mobile game, not a generic website.

- Main button: "PLAY TODAY"

- Add "Today's Challenge", "Your Score", "Global Ranking" and "Share Result".

LANDING PAGE:

- Logo: CLOSE

- Tagline: "How close can you get?"

- Large PLAY TODAY button.

- Show today's global player count.

- Explain the game in 3 very short steps:

  1. Guess

  2. Submit

  3. See how close you are

Create the complete frontend with realistic sample questions and sample ranking data so the game can be played immediately as a demo.

Do NOT create unnecessary pages or complicated features. Focus on making the core game extremely polished and addictive.
